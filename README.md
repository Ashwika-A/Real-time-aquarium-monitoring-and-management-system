**The Real-Time Aquarium Monitoring and Management System(2024-2025)**

The Real-Time Aquarium Monitoring and 
Management System is a smart solution designed to 
maintain optimal aquatic conditions using sensor-based 
monitoring and image processing. Built with an Arduino 
Nano, it integrates sensors like the DS18B20 
(temperature), TDS sensor, and BH1750 (light) to track 
water parameters continuously. 
To support fish health and water quality analysis, 
MATLAB algorithms analyze image data to detect 
common diseases and assess turbidity and color via a 
custom MATLAB App Designer GUI. The system 
supports remote monitoring, real-time alerts, and 
automated visualization, offering aquarium owners an 
intelligent, scalable, and efficient tool for ecosystem 
management. 
Tools used: 
Hardware: Arduino nano, BH1750, DS18B20, TDS 
Sensor, LCD Display. 
Software: Arduino IDE, MATLAB, ThingSpeak
